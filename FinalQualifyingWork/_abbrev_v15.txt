ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ
p15: Pitch – (тангаж) ось на аппаратуре управления, отвечающая за поворот объекта вокруг его поперечной оси.
p16: Roll – (крен) ось на аппаратуре управления, отвечающая за поворот объекта вокруг его продольной оси.
p17: Yaw – (рысканье) ось на аппаратуре управления, отвечающая за поворот объекта вокруг его вертикальной оси.
p18: Throttle – (газ) ось на аппаратуре управления, отвечающая за среднее значение газа на всех двигателя летательного аппарата.
p19: First Person View – сокращение FPV, с англ. — «вид от первого лица».
p20: ELRS (ExpressLRS) – протокол радиоуправления с открытым исходным кодом, разработанный специально для FPV-дронов.
p21: FLRC (Frequency-Locked Rate Control) – режим управления скоростью с частотной блокировкой, который используется в ELRS (ExpressLRS) системе.
p22: Betaflight – открытое программное обеспечение для контроллеров полета беспилотных летательных аппаратов.
p23: Command Line Interface – сокращение CLI, с англ. — «Интерфейс командной строки».
p24: Application Programming Interface – сокращение API, с англ. — «Программный интерфейс».
p25: ESP32 – микроконтроллер, разработанный компанией Espressif Systems с интегрированным Wi-Fi и Bluetooth.
p26: БВС – беспилотное воздушное судно.
p27: RC – Radio Control, радиоуправление.
p28: DCT – Data Collection Toolkit, разработанный программный комплекс.
p29: PF – Particle Filter, фильтр частиц.
p30: YOLO – семейство нейросетевых моделей детектирования объектов.
p31: PnP – Perspective-n-Point, задача восстановления положения камеры по 2D-3D соответствиям.
p32: MAVLink – протокол обмена сообщениями для беспилотных систем.
p33: HEPU – категория горизонтальной навигационной точности.
p34: VEPU – категория вертикальной навигационной точности.
p35: СППИ – система представления полетной информации.
