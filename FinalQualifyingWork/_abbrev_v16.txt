ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ
p15: Ниже приведены сокращения и обозначения, используемые в работе. Сокращения сгруппированы по тематике; математические обозначения согласованы с формулами глав 3–4.
p16: Сокращения
p17: Общие термины и предметная область
p18: БВС — беспилотное воздушное судно.
p19: FPV (First Person View) — управление и наблюдение «от первого лица»; в работе — FPV-дрон исследуемого класса.
p20: GPS — Global Positioning System, глобальная спутниковая навигация.
p21: ГЛОНАСС — глобальная навигационная спутниковая система.
p22: SLAM — simultaneous localization and mapping.
p23: VIO — visual-inertial odometry, визуально-инерциальная одометрия.
p24: INS — inertial navigation system, инерциальная навигационная система.
p25: Каналы радиоуправления (оси стиков)
p26: Pitch — тангаж; Roll — крен; Yaw — рысканье; Throttle — газ (среднее управление тягой). В тексте — RC-каналы [throttle, yaw, pitch, roll].
p27: Радиоуправление, приём данных и полётный контроллер
p28: RC — Radio Control, радиоуправление; в работе — RC-каналы, RC-признаки.
p29: ELRS (ExpressLRS) — протокол радиоуправления с открытым исходным кодом для FPV-дронов.
p30: FLRC (Frequency-Locked Rate Control) — режим управления скоростью с частотной блокировкой в системе ELRS.
p31: EdgeTX — прошивка/экосистема аппаратуры радиоуправления на стороне пилота.
p32: Betaflight — открытое ПО полётного контроллера (профили rate, expo, суперрейт).
p33: ESP32 — микроконтроллер приёмника RC-данных (передача на ПК по COM-порту).
p34: COM — последовательный порт ПК для приёма потока RC.
p35: Цифровой видеотракт FPV
p36: HDZero — экосистема цифрового FPV-видеолинка (передатчик VTX и приёмник VRX).
p37: VTX — video transmitter, передатчик видеосигнала с курсовой камеры.
p38: VRX — video receiver, приёмник видеосигнала (HDZero EventVRX).
p39: Программный комплекс и интерфейсы
p40: DCT — Data Collection Toolkit, разработанный программный комплекс.
p41: Record — режим DCT записи сессии полёта.
p42: Replay — режим DCT воспроизведения и анализа записанной сессии.
p43: CLI — Command Line Interface, интерфейс командной строки.
p44: API — Application Programming Interface, программный интерфейс.
p45: C4 — нотация архитектурных диаграмм (Context, Container, Component).
p46: Алгоритмы локализации, зрения и сглаживания
p47: PF — Particle Filter, фильтр частиц (основной алгоритм локализации).
p48: ESS — effective sample size, эффективное число частиц.
p49: KF — Kalman filter, фильтр Калмана (второй контур сглаживания KFLayer2).
p50: CamKF — экспериментальный контур камерного сглаживания в Replay.
p51: YOLO — семейство нейросетевых моделей детектирования объектов.
p52: PnP — Perspective-n-Point, восстановление положения камеры по 2D–3D соответствиям.
p53: RC+Rate — режим признаков: RC-стики с преобразованием в угловые скорости по профилю Betaflight.
p54: Координаты, протоколы и внешняя система
p55: ENU — East–North–Up, локальная геодезическая система координат.
p56: WGS-84 — World Geodetic System 1984, географические координаты.
p57: MAVLink — протокол обмена сообщениями для беспилотных систем.
p58: UDP — User Datagram Protocol (транспорт MAVLink в NebosvodConnect).
p59: NebosvodConnect — приложение интеграции DCT с системой мониторинга «Небосвод».
p60: Метрики, категории точности и форматы данных
p61: HEPU — категория горизонтальной погрешности навигационной точности.
p62: VEPU — категория вертикальной погрешности навигационной точности.
p63: СППИ — система представления полётной информации.
p64: p90_err_m — 90-й процентиль ошибки локализации, м.
p65: p95_err_m — 95-й процентиль ошибки локализации, м (сопоставление с HEPU).
p66: GT (ground truth) — эталонная (истинная) траектория в экспериментах.
p67: JSONL — JSON Lines (файл camera_observations.jsonl).
p68: NPZ — сжатый архив NumPy (референс трассы, .npz).
p69: Обозначения
p70: s — дуговая координата вдоль референсной трассы, м; v — скорость вдоль трассы, м/с; L — длина референсного круга, м.
p71: s_i, v_i, w_i — положение, скорость и вес i-й частицы PF; Δt — шаг по времени, с; η_v, η_s — возмущения скорости и положения (process_noise_v, process_noise_s).
p72: u_k, ũ_k — k-й признак наблюдения и его z-score; μ_k, σ_k — среднее и СКО признака по эталонному кругу; K — число признаков (каналов).
p73: d_i — невязка RC-признаков частицы i; σ_obs — параметр правдоподобия (obs_sigma); ESS — эффективное число частиц; θ_i, s_est — угол на окружности и оценка положения.
p74: z_obs, σ_cam — камерное наблюдение и неопределённость (xyz_obs, sigma_cam); p(s_i) — 3D-позиция частицы на референсе.
p75: e_t — модуль ошибки локализации в момент t; p_gt, p_est — истинная и оценочная позиции; Q_0,9, Q_0,95 — квантили выборки ошибок.
p76: East, North, Up — компоненты ENU; φ_0, Δλ, Δφ, Δh — широта опорной точки и приращения долготы, широты, высоты; x_loc, z_loc — координаты в локальной СК трассы.
p77: T_k — порог k-й категории HEPU; P(·) — вероятность попадания ошибки в допуск (оценка по p95_err_m).
