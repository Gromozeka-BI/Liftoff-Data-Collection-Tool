# C4-модель комплекса DCT

Для описания архитектуры в ВКР используется нотация **C4** (Context → Container → Component).

Исходник диаграмм (авторская, актуальная):  
`Документы/Схемы/С4_v2.drawio` — вкладки **1. C4 Context**, **2. C4 Container**, **3. C4 Component (DCT)**, **DCT**, **FPV-платформа**, **Nebosvod Connect**.

Черновик в репозитории: **`c4_dct_architecture.drawio`** (Container/Component).

## Уровни и вкладки draw.io

| Вкладка | Уровень C4 | Где в ВКР |
|---------|------------|-----------|
| `1. C4 Context` | System Context | Гл. 1–2, обзор границ системы |
| `2. C4 Container` | Container | **П. 2.1** — общая архитектура комплекса |
| `3. C4 Component (DCT)` | Component | **П. 2.6**, гл. 3 — компоненты внутри DCT Desktop |
| `DCT` | Container (детализация) | DCT Desktop + хранилище сессий |
| `FPV-платформа` | Container (детализация) | аппаратура, дрон, RC, видео |
| `Nebosvod Connect` | Container (детализация) | Desktop + локальный кэш |

## Как открыть в draw.io

1. [https://app.diagrams.net/](https://app.diagrams.net/) → **Open Existing Diagram**.
2. Выбрать `FinalQualifyingWork/figures/c4_dct_architecture.drawio`.
3. Если фигуры отображаются прямоугольниками: **+ More Shapes** → включить библиотеку **C4** → Apply.

Либо в VS Code: расширение **Draw.io Integration** → открыть файл `.drawio`.

## Экспорт в ВКР (Word)

1. Открыть нужную вкладку (для 2.1 — **2. C4 Container**).
2. **File → Export as → PNG** (300 DPI) или **PDF** (вектор).
3. Вставить в `БояриновИР_ВКР_черновик.docx`, подпись по ГОСТ:

   - Context: *Рисунок 2.1 — Контекстная диаграмма C4 комплекса отслеживания БВС*
   - Container: *Рисунок 2.1 — Диаграмма контейнеров C4 комплекса отслеживания БВС*  
     (или 2.1a / 2.2 — если в тексте две диаграммы подряд)

Рекомендуемая ширина в Word: **14–16 см**.

## Соглашения (принятые в проекте)

- **Синий** system/container — в зоне ответственности DCT / разработки в ВКР.
- **Серый** — внешние системы (FPV-платформа, «Небосвод», RC/видео как аппаратные цепочки).
- **NebosvodConnect** — отдельный container/application, не часть репозитория DCT.
- На стрелках: протокол или смысл связи (`COM`, `MAVLink UDP`, `inject_position_observation`).
- Формат подписи узла: `Имя` → `[Тип]` → краткое описание (стандарт C4).

## Связь с прежним SVG

`fig_2_1_architecture.svg` — упрощённая блок-схема «цепочек»; для диплома **основной источник — C4 в draw.io**. SVG можно не использовать или оставить как приложение.

## Обновление диаграммы

После изменений в коде (`dct/localization`, `mavlink_sender`, Record/Replay):

1. Править вкладку **3. C4 Component**.
2. При смене интеграции — вкладки **1** и **2**.
3. Переэкспортировать PNG/PDF и заменить рисунок в Word.
4. Указать в коммите: `figures: update C4 container diagram`.
