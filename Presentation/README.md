## Состав макета PPTX

Оформление взято из **примера Теленков КД ВКР**: титульный (слайд 1) и «Спасибо за внимание» (слайд 17 примера). Контентные слайды — по макету слайда «Цель и задачи» (логотип МАИ, заголовок #0095DA, номер слайда).

1. **Титульный** — шапка МАИ из шаблона + тема DCT + заглушки [ФИО]
2. **Слайды 2–19** — 18 слайдов по плану + заметки докладчика
3. **Слайд 20** — «Спасибо за внимание» из шаблона

**Цвет акцента:** `#0095DA` (RGB 0, 149, 218).

На слайдах **14–17** подставлены графики из `tools/exp*/plots/`. Остальные визуалы — подпись-подсказка справа, что вставить из ВКР.
