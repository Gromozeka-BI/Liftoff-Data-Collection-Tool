# Модуль: gate_model

## За что отвечает

Вычисляет **мировые 3D-координаты четырёх внутренних углов** ворот по их описанию из карты трека (`track.json`).

Является единственным источником 3D-координат во всём пайплайне — и для калибровки, и для PnP-локализации.

---

## Система координат

Используется мировая система координат симулятора Liftoff:
- **Y-up**: ось Y направлена вертикально вверх
- **X, Z — горизонтальные** оси
- `position` в `track.json` — это **нижняя центральная точка** ворот (bottom center), **не** геометрический центр
- Поворот задаётся как `rotation[1]` — угол yaw вокруг оси Y (в градусах)

---

## Формат ворот в track.json

```json
{
  "id": 0,
  "position": [25.57, 0.0, 7.33],
  "rotation": [0.0, 90.0, 0.0],
  "size": [1.56, 1.56],
  "radius": 2.0
}
```

| Поле | Описание |
|---|---|
| `position` | [x, y, z] нижней центральной точки (bottom center) |
| `rotation[1]` | yaw в градусах, поворот вокруг Y |
| `size[0]` | ширина просвета (w), по горизонтали |
| `size[1]` | высота просвета (h), по вертикали |

---

## Геометрия углов

Локальные координаты углов (до поворота), относительно `position`:

```
inner_top_left    = (-w/2,  h, 0)
inner_top_right   = ( w/2,  h, 0)
inner_bottom_right= ( w/2,  0, 0)
inner_bottom_left = (-w/2,  0, 0)
```

Применяется поворот вокруг Y (yaw) → получаем мировые координаты:

```
corner_world = position + R_y(yaw) @ corner_local
```

где `R_y(θ)` — матрица правостороннего поворота вокруг оси Y.

---

## Приподнятые ворота (elevated gates)

Ворота 9, 13, 21 установлены на стойках: их `position.y = 1.855 > 0`.  
Формула остаётся той же — `position` уже содержит смещение по Y.  
Нет специальной обработки: обычные ворота имеют `position.y = 0`.

## Запуск (проверка)

```bash
# Из корня репозитория — сравнить расчётные углы с эталонными из calibration_frames_card.json
python src/gate_model/gate_model.py --verify

# Получить углы одного ворота
python src/gate_model/gate_model.py --gate-id 0
```
