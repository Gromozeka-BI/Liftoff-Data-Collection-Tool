# Выходные данные сессии записи полёта

Дата: 2026-05-12

Этот документ описывает все файлы и поля, которые создаются в папке сессии при записи полёта в DCT.

---

## Структура папки сессии

Каждая сессия сохраняется в отдельную папку вида:

```
sessions/
└── YYYY-MM-DD_pilot-{pilot}_drone-{drone}_track-{track}_session-{NNN}/
    ├── meta.json                  # обязательный
    ├── events.parquet             # обязательный
    ├── telemetry.parquet          # при наличии Liftoff UDP
    ├── rc_channels.parquet        # при наличии RC (GUI)
    ├── timeline.parquet           # GUI
    ├── video.mp4                  # при включённой записи видео
    ├── video_timestamps.parquet   # при включённой записи видео
    ├── track.json                 # если трасса найдена
    ├── invert.json                # GUI
    ├── rate_profile.json          # GUI, если задан профиль
    ├── camera_profile.json        # GUI, если задан профиль
    ├── system.jsonl               # GUI
    └── events_edited.parquet      # Replay, при редактировании событий
```

Счётчик `NNN` начинается с `001` и инкрементируется для каждой новой сессии с тем же префиксом в тот же день.

## Файлы и их поля

### `meta.json`

Метаданные сессии. Создаётся при старте, дополняется при завершении.

| Поле               | Тип     | Описание                                                    |
|--------------------|---------|-------------------------------------------------------------|
| `version`          | string  | Версия формата (`"0.1"`)                                    |
| `session_id`       | string  | Имя папки сессии                                            |
| `pilot`            | string  | Идентификатор пилота                                        |
| `drone`            | string  | Идентификатор дрона                                         |
| `track`            | string  | Идентификатор трассы                                        |
| `purpose`          | string  | Цель записи (например, `"train"`, `"ref"`)                  |
| `created_at`       | string  | ISO-время начала сессии (UTC)                               |
| `finished_at`      | string  | ISO-время конца сессии (UTC); `null` до завершения          |
| `duration_s`       | float   | Длительность сессии, сек; `null` до завершения              |
| `total_packets`    | int     | Количество принятых Liftoff UDP пакетов                     |
| `total_laps`       | int     | Количество зафиксированных кругов                           |
| `validated`        | bool    | Флаг валидации (`false` по умолчанию)                       |

Дополнительные поля, добавляемые GUI при наличии профилей:

| Поле                | Тип    | Описание                              |
|---------------------|--------|---------------------------------------|
| `data_source`       | string | Режим источника данных (`"liftoff"`, `"rc"`, `"both"`) |
| `rate_profile_id`   | any    | ID профиля рейтов                     |
| `rate_profile_name` | string | Название профиля рейтов               |
| `camera_id`         | any    | ID профиля камеры                     |
| `camera_name`       | string | Название профиля камеры               |

Пример:

```json
{
  "version": "0.1",
  "session_id": "2026-05-12_pilot-Alice_drone-MadTrainer_track-track-001_session-001",
  "pilot": "Alice",
  "drone": "MadTrainer",
  "track": "track-001",
  "purpose": "train",
  "created_at": "2026-05-12T09:00:00+00:00",
  "finished_at": "2026-05-12T09:05:00+00:00",
  "duration_s": 300.0,
  "total_packets": 29800,
  "total_laps": 5,
  "validated": false,
  "data_source": "both",
  "rate_profile_id": "betaflight_classic_v1",
  "rate_profile_name": "Betaflight Classic"
}
```

### `telemetry.parquet`

Основная телеметрия из симулятора Liftoff. Одна строка ≈ один UDP-пакет (~100 Гц).

| Поле         | Тип     | Единица | Описание                                          |
|--------------|---------|---------|---------------------------------------------------|
| `seq`        | int64   | —       | Монотонный номер пакета в рамках сессии           |
| `ts_wall`    | float64 | с       | Время ПК (Unix seconds, `time.time()`)            |
| `ts_sim`     | float32 | с       | Внутренний таймер симулятора                      |
| `pos_x`      | float32 | м       | Позиция по оси X                                  |
| `pos_y`      | float32 | м       | Позиция по оси Y                                  |
| `pos_z`      | float32 | м       | Позиция по оси Z                                  |
| `att_x`      | float32 | —       | Кватернион ориентации, компонент X                |
| `att_y`      | float32 | —       | Кватернион ориентации, компонент Y                |
| `att_z`      | float32 | —       | Кватернион ориентации, компонент Z                |
| `att_w`      | float32 | —       | Кватернион ориентации, компонент W                |
| `vel_x`      | float32 | м/с     | Скорость по оси X                                 |
| `vel_y`      | float32 | м/с     | Скорость по оси Y                                 |
| `vel_z`      | float32 | м/с     | Скорость по оси Z                                 |
| `gyro_pitch` | float32 | град/с  | Угловая скорость по оси Pitch                     |
| `gyro_roll`  | float32 | град/с  | Угловая скорость по оси Roll                      |
| `gyro_yaw`   | float32 | град/с  | Угловая скорость по оси Yaw                       |
| `in_throttle`| float32 | −1..1   | Входной стик газа                                 |
| `in_yaw`     | float32 | −1..1   | Входной стик рыскания                             |
| `in_pitch`   | float32 | −1..1   | Входной стик тангажа                              |
| `in_roll`    | float32 | −1..1   | Входной стик крена                                |
| `bat_v`      | float32 | В       | Напряжение батареи                                |
| `bat_pct`    | float32 | %       | Заряд батареи                                     |
| `motor_0`    | float32 | RPM     | Обороты мотора 0 (`NaN`, если не поступили)       |
| `motor_1`    | float32 | RPM     | Обороты мотора 1 (`NaN`, если не поступили)       |
| `motor_2`    | float32 | RPM     | Обороты мотора 2 (`NaN`, если не поступили)       |
| `motor_3`    | float32 | RPM     | Обороты мотора 3 (`NaN`, если не поступили)       |

### `rc_channels.parquet`

Сырые каналы RC-аппаратуры, принимаемые по UART (ESP32/ELRS). Только GUI.

| Поле           | Тип     | Единица | Описание                                              |
|----------------|---------|---------|-------------------------------------------------------|
| `seq`          | int64   | —       | Монотонный номер RC-пакета в рамках сессии            |
| `ts_wall`      | float64 | с       | Время ПК, вычисленное из якоря и `micros()` устройства|
| `ts_device_us` | int64   | мкс     | Значение `micros()` на ESP32 в момент отправки пакета |
| `ch1`          | int32   | мкс     | Канал 1 (~988..2012)                                  |
| `ch2`          | int32   | мкс     | Канал 2                                               |
| `ch3`          | int32   | мкс     | Канал 3                                               |
| `ch4`          | int32   | мкс     | Канал 4                                               |
| `ch5`          | int32   | мкс     | Канал 5                                               |
| `ch6`          | int32   | мкс     | Канал 6                                               |
| `ch7`          | int32   | мкс     | Канал 7                                               |
| `ch8`          | int32   | мкс     | Канал 8                                               |

Соответствие каналов осям зависит от конфигурации аппаратуры.

### `events.parquet`

Дискретные события сессии: старт/стоп, прохождение ворот, регистрация кругов.

| Поле         | Тип     | Описание                                                                 |
|--------------|---------|--------------------------------------------------------------------------|
| `seq`        | int64   | Монотонный номер события в рамках сессии                                 |
| `ts_wall`    | float64 | Время события (Unix seconds)                                             |
| `event_type` | string  | Тип события (см. таблицу ниже)                                           |
| `gate_id`    | int32   | ID ворот; `-1`, если неприменимо                                         |
| `lap_num`    | int32   | Номер круга; `-1`, если неприменимо                                      |
| `source`     | string  | Источник события (`"rh"`, `"button"`, `"writer"` и др.)                 |

Типы событий (`event_type`):

| Значение        | Источник      | Описание                                  |
|-----------------|---------------|-------------------------------------------|
| `session_start` | writer        | Запись началась                           |
| `session_stop`  | writer        | Запись завершена                          |
| `rh_lap`        | RacerHelper   | Зафиксирован круг через RacerHelper       |
| `rh_gate`       | RacerHelper   | Пройдены ворота через RacerHelper         |
| `button_lap`    | HTTP кнопка   | Зафиксирован круг через HTTP-эндпоинт    |
| `button_gate`   | HTTP кнопка   | Пройдены ворота через HTTP-эндпоинт      |

### `events_edited.parquet`

Создаётся при редактировании событий в режиме Replay. Схема идентична `events.parquet`. Исходный файл при этом не изменяется.

---

### `timeline.parquet`

Равномерная временна́я шкала (~30 Гц) для работы Replay и seek. Только GUI.

| Поле      | Тип     | Описание                          |
|-----------|---------|-----------------------------------|
| `seq`     | int64   | Монотонный номер тика             |
| `ts_wall` | float64 | Время тика (Unix seconds)         |

Позволяет Replay корректно работать даже в режиме RC-only, когда телеметрии нет.

---

### `video.mp4`

Видеозапись экрана или capture card. Контейнер MP4, кодек H.264.

Создаётся только при включённой записи видео (`no_video = false`).

---

### `video_timestamps.parquet`

Точные временны́е метки для каждого кадра видео. Позволяет синхронизировать видео с телеметрией и событиями по `ts_wall`.

| Поле        | Тип     | Описание                                         |
|-------------|---------|--------------------------------------------------|
| `frame_idx` | int64   | Индекс кадра (0-based)                           |
| `ts_wall`   | float64 | Время записи кадра на ПК (Unix seconds)          |

Создаётся совместно с `video.mp4`.

---

### `track.json`

Копия конфигурации трассы, зафиксированная на момент записи. Содержит описание ворот, координаты, радиусы проверки и другие параметры из файла трассы.

---

### `rate_profile.json`

Копия профиля рейтов, активного во время записи. Структура соответствует файлам из `profiles/rates/*.json`. Только GUI.

---

### `camera_profile.json`

Копия профиля камеры, активного во время записи. Структура соответствует файлам из `profiles/cameras/*.json`. Только GUI.

---

### `invert.json`

Сохранённое состояние инверсий осей на графиках стиков в момент старта сессии. Используется Replay для восстановления корректного вида. Только GUI.

---

### `system.jsonl`

Технический журнал системных событий. Каждая строка — отдельный JSON-объект:

```jsonl
{"ts_wall": 1715500000.0, "event": "rc_online", "port": "COM3"}
{"ts_wall": 1715500001.5, "event": "source_config", "data_source": "both"}
```

| Поле      | Тип    | Описание                                |
|-----------|--------|-----------------------------------------|
| `ts_wall` | float  | Время события (Unix seconds)            |
| `event`   | string | Тип системного события                  |
| ...       | any    | Дополнительные поля зависят от события  |

Создаётся только GUI.

| `video_timestamps.parquet` | опц.            | опц.             | опц.        | опц.           |
| `track.json`            | если найдена       | если найдена     | если найдена| если найдена   |

| `system.jsonl`          | —                  | ✓                | ✓           | ✓              |

## Эталонные файлы трассы (не сессия)

При построении локализационного эталона через `dct build-ref` создаётся пара файлов в папке трассы:

```
tracks/
└── {track_id}/
    └── references/
        ├── {profile}.npz           # массивы эталона
        └── {profile}.meta.json     # метаданные эталона
```

### `{profile}.meta.json`

| Поле             | Тип    | Описание                                                  |
|------------------|--------|-----------------------------------------------------------|
| `track_id`       | string | Идентификатор трассы                                      |
| `profile`        | string | Имя эталона                                               |
| `built_at`       | string | ISO-время построения (UTC)                                |
| `source`         | string | Путь к исходной сессии                                    |
| `lap_index`      | int    | Индекс круга, использованного для построения              |
| `smooth_w`       | int    | Ширина окна сглаживания                                   |
| `track_length_m` | float  | Длина трассы, м                                           |
| `frames`         | int    | Количество кадров в эталоне                               |
| `metrics`        | object | Метрики качества эталона (может быть пустым)              |
| `feature_kind`   | string | Тип признаков: `"betaflight_classic_rpy_deg_s_v1"` или `"legacy_sticks"` |

### `{profile}.npz`

NumPy-архив (сжатый). Содержит массивы:

| Ключ               | Shape              | Тип      | Описание                                                  |
|--------------------|--------------------|----------|-----------------------------------------------------------|
| `s`                | `(N,)`             | float64  | Параметр дистанции вдоль трассы, м                        |
| `pos`              | `(N, 3)`           | float64  | Позиции (X, Y, Z) вдоль трассы, м                        |
| `sticks_norm`      | `(N, D)`           | float64  | Нормализованные признаки стиков                           |
| `mean`             | `(D,)`             | float64  | Среднее для z-score нормализации                          |
| `std`              | `(D,)`             | float64  | Стандартное отклонение для z-score нормализации           |
| `smooth_w`         | scalar             | int      | Ширина окна сглаживания                                   |
| `feature_kind`     | scalar (опц.)      | string   | Тип признаков (если указан)                               |
| `rate_profile_json`| `(M,)` uint8 (опц.)| uint8   | JSON-байты профиля рейтов (если задан)                    |

`N` — количество кадров эталона, `D` — размерность вектора признаков (зависит от `feature_kind`).

Загрузка:

```python
import numpy as np
data = np.load("RED_v2.npz", allow_pickle=False)
s    = data["s"]     # дистанция
pos  = data["pos"]   # координаты
```
