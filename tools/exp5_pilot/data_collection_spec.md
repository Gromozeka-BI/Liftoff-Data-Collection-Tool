# ТЗ для пилота — Эксперимент 5 (Drone Coordinate Tracker)

**Кому**: второй пилот (<Callsign>)  
**Что нужно**: записать несколько полётных сессий в симуляторе Liftoff  
**Для чего**: тест системы трекинга дронов по трассе — исследование влияния стиля пилотирования  
**Ориентировочное время**: 2–3 часа

---

## Шаг 1. Подготовка

### Необходимое ПО
- **Liftoff: Micro Gates** (Steam) — то же, что стоит у Громозеки
- **DCT** (Drone Coordinate Tracker) — запросить у Громозеки установочный файл
- **RC пульт** — твой физический пульт, подключённый к ПК

### Настройка Liftoff
1. Открой Liftoff → Custom Tracks → загрузи трек **track-002**
   *(файл трека передаст Громозека)*
2. В качестве дрона выбери **MadTrainer**
3. Управление — RC пульт через USB/Bluetooth *(стандартная настройка)*

### Рейт-профили
Тебе нужно будет записать сессии с **двумя разными рейт-профилями**:

- **Gromozeka_rate** — профиль Громозеки (файл передаст он)
  Загрузи в Liftoff: Settings → Rates → Import → `Gromozeka_rate.json`

- **Твой рейт-профиль** — твои обычные настройки, с которыми ты летаешь

---

## Шаг 2. Обязательные сессии (4 штуки)

### Порядок записи

**Перед первой сессией**: сделай 5–10 разогревочных кругов без записи,
чтобы привыкнуть к треку. Это важно — ты должен лететь в свою обычную силу,
а не изучать трасу во время записи.

---

### Сессия 1 — MadTrainer × Gromozeka_rate × 12 лапов

| Параметр | Значение |
|---|---|
| Дрон | MadTrainer |
| Рейт-профиль | **Gromozeka_rate** |
| Минимум лапов | **12** |
| DCT режим | Запись включена |

**Процедура**:
1. Установи рейт Gromozeka_rate в Liftoff
2. Запусти DCT → нажми **«Новая сессия»** → убедись: статус «Запись»
3. Начни летать. Пролети стартовую линию → без остановки лети следующий круг
4. После **12+ лапов** нажми **«Стоп»** в DCT
5. Запиши название папки сессии (DCT покажет путь)

---

### Сессия 2 — MadTrainer × Gromozeka_rate × 10 лапов (повтор)

Аналогично Сессии 1. Небольшой перерыв (5–10 минут) между сессиями — норма.

## Шаг 4. Что делать во время полёта

### ✅ Делай так

- Лети **в полную силу** — как на соревнованиях, твоя обычная манера
- Завершай каждый круг **проходя через стартовую линию**
- Продолжай летать **без остановок** между кругами
- Если упал — **не останавливай DCT**, взлетай и летай дальше
  (система автоматически помечает плохие лапы)

### ❌ Не делай так

- Не зависай на месте больше 5 секунд в середине трассы
- Не останавливай сессию после каждого лапа
- Не летай специально медленно или аккуратно — нужна твоя естественная скорость

## Шаг 5. Создание референса в DCT (после записи)

После записи всех сессий нужно создать **референсный файл** — это запись одного
идеального круга, по которому система будет ориентироваться.

1. Открой DCT → вкладка **«Референсы»** → трек **track-002**
2. Выбери **Сессию 1** → посмотри на список лапов
3. Выбери лап с **наименьшим временем** (или наиболее чистый по графику)
4. Нажми **«Создать референс»**
5. В поле «Название» введи: `<твой_callsign>_1`
   *(например, если тебя зовут RedSeep → `RedSeep_1`)*
6. Нажми **«Сохранить»**
7. Повтори для **Сессии 2** → назови `<твой_callsign>_2`

---

## Шаг 6. Передача данных Громозеке

Передай следующие файлы/папки:

### Папки сессий
Все 4–6 записанных сессий. Путь обычно:
```
D:\DroneTrackerDB\Liftoff\<PartX>\
    2026-XX-XX_pilot-<Callsign>_drone-MadTrainer_track-track-002_session-00X\
```

### Файлы референсов
```
tracks/track-002/references/
    <Callsign>_1.npz
    <Callsign>_1.meta.json
    <Callsign>_2.npz
    <Callsign>_2.meta.json
```

### Твой рейт-профиль
Если у тебя нестандартный рейт — передай файл профиля (`.json`)
чтобы Громозека мог его использовать при обработке данных.
