# Эксперимент 7: Временна́я стабильность

## Статус: ГОТОВ К ЗАПУСКУ

---

## 1. Исследовательский вопрос

> Деградирует ли точность локализатора по мере увеличения числа пройденных
> лапов? Нужно ли сбрасывать фильтр между сессиями или он устойчив к дрейфу?

---

## 2. Предшествующие знания

В Exp 1–4 всегда использовались последние 3 лапа сессии (N_LAST_LAPS=3).
Непрерывный фильтр запускался сквозь все 3 лапа без сброса. Поведение
фильтра на более длинных горизонтах (10+ лапов) не исследовалось.

Практическая мотивация: в реальном применении дрон может лететь 10–30 лапов
без остановки. Важно понять, сохраняется ли точность.

## 3. Факторы и уровни

| Фактор | Уровни | Описание |

Flight 2 (MadTrainer, RedSheep_rate) — 5 лапов.

## 4. Гипотезы

| # | Гипотеза | Ожидаемый результат |
|---|---|---|
| H1 | p90 не деградирует с ростом номера лапа | p90(lap_10) ≈ p90(lap_1), разница < 20% |
| H2 | Если деградация есть — она больше для cross-drone | |trend_cross| > |trend_same| |
| H3 | Первые 2 лапа хуже последующих (период сходимости) | p90(lap_1) > p90(lap_3) |

## 5. Дизайн

### 5.1 Схема запуска фильтра

```
Запуск фильтра с нуля (loc.reset())
    └─> lap 1 → записать p90_lap1
    └─> lap 2 → записать p90_lap2   (без reset между лапами!)
    └─> lap 3 → записать p90_lap3
    └─> ...
    └─> lap N → записать p90_lapN
```

Фильтр **НЕ сбрасывается** между лапами — это симулирует реальное
непрерывное использование.

### 5.2 Метрика per-lap

Для каждого лапа вычислять `p90_err_m` и `median_err_m` независимо —
чтобы видеть тренд по лапам.

### 5.3 Трендовый анализ

Линейная регрессия `p90 ~ lap_index` для определения наличия тренда.
Slope > 0 → деградация. Slope < 0 → улучшение (сходимость).

---

## 6. Метрики

- `p90_err_m` per lap — тренд по времени
- `median_err_m` per lap
- Slope линейной регрессии (м/лап)
- Стандартизованное отклонение p90 между лапами (нестабильность)
