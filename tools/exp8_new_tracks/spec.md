# Эксперимент 8: Генерализация на новые треки

## Статус: ОЖИДАЕТ ДАННЫХ

---

## 1. Исследовательский вопрос

> Сохраняется ли точность локализатора (p90 < 15 м) при переходе на
> незнакомые треки без повторной оптимизации гиперпараметров?

Это тест **генерализации конфигурации**: параметры, найденные на track-002
в Exp 3 (`sigma=2.0, pnv=8.0, no_thr`), применяются "из коробки" к
совершенно новым трекам. Именно это важно для практического применения.

---

## 2. Предшествующие знания

- Exp 3: Оптимальные параметры для track-002 — sigma=2.0, pnv=8.0, preset=no_thr.
- Exp 4: Качество референса важнее типа дрона; GromFF_1 даёт p90=5.8–9.7 м.
- Неизвестно: работают ли эти параметры на треках другой геометрии и длины.

---

## 3. Что нужно подготовить (данные)

### 3.1 Создать 2 новых трека

| Трек | Рекомендации |
|---|---|
| **track-003** | Отличается от track-002 по геометрии (например, более технический/медленный) |
| **track-004** | Ещё один трек, желательно другой длины (короче или длиннее track-002) |

Треки создаются в **редакторе Liftoff** или берутся из библиотеки Community Tracks.

### 3.2 Записать полёты

**Для каждого трека** записать:
- Пилот: Gromozeka
- Дрон: MadTrainer
- Rate: Gromozeka_rate
- Минимум: **4 сессии × 10+ лапов** (для надёжной статистики)

### 3.3 Создать референс через DCT GUI

- Для track-003: `GromFF_track003_1.npz`
- Для track-004: `GromFF_track004_1.npz`

Использовать те же настройки, что для GromFF_1 (smooth_w=5, best lap).

---

## 4. Дизайн

**Метод**: применить конфигурацию из Exp 3 **без оптимизации**.

| Параметр | Значение | Обоснование |
|---|---|---|
| obs_sigma | 2.0 | Оптимум Exp 3 на track-002 |
| process_noise_v | 8.0 | Оптимум Exp 3 на track-002 |
| preset | no_thr | Лучший из Exp 3 |
| Mode | RC+Rate | Лучший из Exp 1 |

**Сравнение**: для каждого трека показать p90 vs целевой порог 15 м.

**Дополнительно** (если есть время): провести мини-свип sigma×pnv
для каждого нового трека, чтобы оценить "цену" переноса параметров.

---

## 5. Гипотезы

| # | Гипотеза | Ожидаемый результат |
|---|---|---|
| H1 | Параметры из Exp 3 достигают p90 < 15 м на новых треках без оптимизации | Подтверждено/не подтверждено |
| H2 | Оптимальные параметры для новых треков близки к track-002 оптимуму | |sigma_opt_new - 2.0| < 0.5 |
| H3 | Длина трека влияет на оптимальный pnv (длиннее → нужен больший pnv) | Корреляция длины и pnv_opt |

---

## 6. Метрики

- `p90_err_m` — первичная (относительно порога 15 м)
- `median_err_m`, `jump_rate`
- "Цена переноса": `p90_transferred - p90_optimized` (если делаем мини-свип)
